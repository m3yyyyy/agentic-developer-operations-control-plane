# Contributing

Thank you for improving RelayOps.

1. Create a focused branch from `main`.
2. Keep new tools read-only by default. Document every side effect and approval rule.
3. Add or update tests for policy and state-machine changes.
4. Run `npm run check` before opening a pull request.
5. Explain the security boundary and validation evidence in the pull request.

Changes that add real shell execution, real repository mutation, credential access, or approval bypasses are outside this public demo's scope.
